Principais Conceitos Estruturais:

  • Auth & Profiles: A tabela `auth.users` é gerenciada estritamente pelo Supabase Auth. A tabela `profiles` na aba pública estende esses dados com as permissões da plataforma (ex: coluna role determinando acessos de mentor, mentee ou admin).
  • Appointments: O coração das mentorias. Vincula um Mentorado e um Mentor. Ele controla o status de agendamento e hospeda o link dinâmico do google_meet_link gerado via API do Google.
  • AI Diagnostics: Respostas de Quiz e Sessões de Diagnóstico são armazenadas usando o poder do JSONB no PostgreSQL, o que permite flexibilidade absurda para os Prompts da Inteligência Artificial. E o diagnostic_shares cuida do controle de acesso RLS para mentores verem diagnósticos compartilhados.
  • Organizações (B2B): A tabela relacional (N:M) organization_members define se um usuário faz parte do hub privado de uma ONG/Empresa e se tem permissão de gerir membros (admin).
