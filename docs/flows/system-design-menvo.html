System Design Menvo

Visão do Fundador: Arquitetura, Infraestrutura, UX/UI e Tecnologias.

"O Menvo não é apenas um software, é um ecossistema digital para democratizar o acesso à mentoria voluntária. A arquitetura foi pensada para ser escalável, sem fricção, altamente automatizada (agendamentos e vídeo) e potencializada por Inteligência Artificial para extrair o máximo de valor das jornadas individuais, tudo isso com uma experiência de usuário (UX) premium e acessível."

— Visão do Fundador

1

UX / UI & Frontend

A interface é a vitrine da democratização do Menvo. Utilizando Next.js 15 (App Router), a aplicação entrega páginas estáticas extremamente rápidas (SEO amigável) combinadas com interações dinâmicas.

  • Design System: Tailwind CSS aliado a blocos do Shadcn/UI garante consistência, modo escuro (Dark Mode), responsividade e total aderência às diretrizes de acessibilidade (WCAG AA).
  • Gerenciamento de Estado: React Hook Form + Zod para formulários blindados. Zustand para o estado do usuário e TanStack Query para cache eficiente.
  • Localização: Suporte multi-idiomas nativo via Next-Intl.
2

Backend & Serverless

A arquitetura foi projetada para não haver servidores ociosos. Tudo roda na "Borda" (Edge) através da infraestrutura da Vercel.

  • Server Actions: Mutação de dados de forma nativa e segura, sem precisar expor endpoints REST desnecessários.
  • Arquitetura Desacoplada: Lógica de negócio encapsulada em "Services" (ex: `mentorshipService.ts`, `quizService.ts`) permitindo testes isolados e reuso.
  • Zero Maintenance: Escala automaticamente do 1º ao milésimo usuário sem preocupação com load balancers ou infraestrutura manual.
3

Banco de Dados e Segurança

Toda a camada de dados e autenticação é terceirizada com maestria para o Supabase (PostgreSQL como serviço).

  • Row Level Security (RLS): Regras de segurança gravadas diretamente no banco de dados. Um mentorado jamais consegue ler os dados privados de outro, independente do que o frontend solicite.
  • Storage: Armazenamento otimizado para currículos e fotos de perfil via buckets S3-compatíveis, com chaves de acesso assinadas de curta duração.
  • Tipagem Forte: O schema do banco gera tipos em TypeScript, criando um ecossistema 100% type-safe do banco ao botão na tela.
4

Integrações Inteligentes (A Diferenciação)

É aqui que a visão do fundador ganha tração em escala: tirando o atrito da relação humana.

  • Sincronia Mágica (Google GCP): O mentor só precisa de 1 clique. O Menvo lê a agenda (Free/Busy), oculta horários ocupados no perfil e, quando um agendamento é fechado, cria a sala do Google Meet automaticamente e põe na agenda dos dois.
  • IA Educacional: LLMs embutidos avaliam os formulários de diagnóstico do mentorado em tempo real, entregando recomendações personalizadas e poupando tempo valioso nas sessões de mentoria.
