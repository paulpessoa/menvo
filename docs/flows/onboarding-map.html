🗄️ Armazenamento de Estado

Opção A — JSONB em profiles (Recomendada)

ALTER TABLE profiles
ADD COLUMN onboarding_flags jsonb NOT NULL DEFAULT '{}';

-- Exemplo: { "ob_m1": "2026-10-02T14:00:00Z", "ob_m2": "2026-10-02T14:05:00Z" }

Prós: Zero tabela nova, leitura no mesmo request de /api/auth/me.
Contras: Não dá para fazer queries complexas por flag (mas não precisamos).

❓ Decisões em Aberto

  1. Mentor-exemplo: Usar o Paul Pessoa real (agenda sempre com slots) ou criar um mentor "fantasma"? → Recomendação: Paul Pessoa real.
  2. Idioma dos tours: Usar chaves de i18n (messages/{pt-BR,en,es}.json) desde o início? → Recomendação: Sim.
