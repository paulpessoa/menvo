5. Antes de qualquer código

Remetente: o único sender no Brevo é "Lista Pronta" <paulmspessoa@gmail.com>. Autenticar menvo.com.br (DKIM/DMARC) e criar "Menvo <contato@menvo.com.br>".

Supabase Auth: configurar o SMTP do Brevo (smtp-relay.brevo.com:587) — o SMTP padrão é só para testes.

Vercel Hobby: cron 1x/dia. Precisa de mais? pg_cron + pg_net no Supabase chamando a mesma rota.
